RQ2 · How it works · Sheets + Apps Script

One click turns a checklist into a report

Input

Tick Accomplished or Needs Improvement per indicator in a sidebar

Process

Scores convert to a 4-point scale and save to a central database

Output

PDF report emailed to the teacher; the dashboard updates

(~55 sec) Architecture. Built on what the school already has — Google Sheets as the database, Google Apps Script for the automation. No extra software, no extra cost. It’s an Input–Process–Output flow: - INPUT: the coordinator opens a custom menu — “CM Analytics Encoder 3.0” — and a sidebar appears (point to screenshot). Teacher, trimester, school year, then each indicator: Accomplished or Needs Improvement. - PROCESS: on submit, the raw marks become a 4-point score and are stored in the database. - OUTPUT: a PDF performance report goes straight to the teacher’s inbox through Gmail, and the dashboard updates for the coordinator. For COT, the coordinator can “Send to Me” first to verify, then “Send to Teacher”, or save as draft.
